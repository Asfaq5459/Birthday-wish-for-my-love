- **HTML5** — Structure and content

- **JavaScript** — Interactive flowers, scene transitions, music controls, and floating effects

## 🚀 Run It Locally

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Place your music file inside `Public/music.mp3`.
4. Open `index.html` in your browser.
5. Choose a flower, play the music, and enjoy the magic! ✨
